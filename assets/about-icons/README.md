# About card icon sources

The files in assets/about-icons are local, unmodified SVG responses from the
same providers already referenced by the README:

- Skill Icons: HTML5, CSS3, JavaScript, TypeScript, React, Figma, Java, Python,
  Spring Boot, Node.js, Apache Maven, Gradle, Git, GitHub, Docker, Bash, Vercel,
  Visual Studio Code, and IntelliJ IDEA.
- Go Skill Icons: Framer, Swagger, n8n, Codex, Claude Code, and Google AI Studio.
- Local repository asset: Hostinger.
- Shields.io: Gmail, LinkedIn, Instagram, WhatsApp, and Discord badges.

The generator prefixes internal IDs while embedding these assets so repeated
filters, gradients, and clip paths remain valid in one SVG document.
